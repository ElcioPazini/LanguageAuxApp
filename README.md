# Language Learning Web App

This is a simple web app I'm building for practice and learning purposes.

The main goal of this project is to practice web development with Vue and Node.js while creating a small application to help me study languages.

## How to Run

Make sure you have [Node.js](https://nodejs.org/) installed.

1. Clone or download the repository.
2. Open a terminal in the project folder.
3. Run:

```bash
node app.js
```

4. Open your browser and go to:

```text
http://localhost:3000
```

This project is mainly for learning and experimentation, so it may change as I continue developing it.
